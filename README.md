## 📖 Overview

**DivineCode** is a full-stack platform designed to bridge competitive programming and technical hiring. It enables developers to practice coding, compete in real-time contests, collaborate with teammates, participate in AI-powered mock interviews, and connect with recruiters—all within a single ecosystem.

The platform is built with a scalable architecture that emphasizes low-latency communication, asynchronous processing, and modular backend services.

---

## ✨ Key Features

- 🏆 Live coding contests with automatic rankings
- ⚔️ Real-time one-on-one coding duels
- 🤖 AI-powered technical interviews using **Gemini API**
- 👥 Collaborative coding workspaces with **Monaco Editor**
- 🎥 Integrated **Jitsi Meet** interview rooms
- 💬 Community discussions and forums
- 📈 Personalized analytics dashboard
- 🏅 Rating and leaderboard system
- 🔒 Secure authentication and role-based authorization

| Queue System | BullMQ + Redis |
| Code Execution | Judge0 API |
| AI Services | Gemini API |

# ⚙️ Simplex Assembler & Emulator
### *A Complete Two-Pass Assembler and CPU Emulator*

<div align="center">

**Modern C++ • Compiler Design • Computer Architecture**

</div>

<div align="center">

📂 **Repository:** https://github.com/Rahul-1-eng/simplex-assembler-emulator

</div>

---

## 📖 Overview

Built a complete assembler and emulator for a custom **32-bit Instruction Set Architecture (ISA)** from scratch. The project simulates the complete lifecycle of machine code—from parsing assembly instructions to executing binary programs inside a simulated processor.

---

## ✨ Features

- Two-pass assembler
- Symbol table generation
- Label resolution
- Object code generation
- Memory simulation
- Register simulation
- Instruction execution
- Execution tracing
- Error diagnostics
- Listing file generation

---

## 🏗️ Implementation

| Component | Description |
|----------|-------------|
| Lexer | Token-based lexical analyzer |
| Parser | Recursive-descent parser |
| Assembler | Two-pass assembler with label resolution |
| Emulator | Fetch–Decode–Execute CPU simulation |
| ISA | Custom 32-bit instruction format |
| Runtime | Simulated registers and memory |

---

## ⚡ Engineering Highlights

- Built entirely using **Modern C++** without external libraries.
- Implemented a complete compiler pipeline from lexical analysis to execution.
- Simulated a custom CPU architecture with detailed execution tracing.
- Validated the implementation using sorting, searching, and factorial programs.

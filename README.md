**DivineCode** is a full-stack platform combining competitive programming with technical hiring.

It supports coding contests, real-time coding duels, collaborative coding, AI-powered interviews, analytics, and technical hiring workflows.

The project focuses heavily on **real-time communication, asynchronous processing, scalable backend architecture, and database-driven applications**.

* ⚔️ Real-time one-on-one coding duels
* 🤖 AI-powered technical interviews using **Gemini API**
* 👥 Collaborative coding using **Monaco Editor and Yjs**
* 🎥 Integrated **Jitsi Meet** interview rooms
* 💬 Community discussions and forums
* 📈 Personalized analytics dashboard
* 🏅 Rating and leaderboard system
* 🔒 Authentication and role-based authorization

# ⚙️ Simplex Assembler & Emulator

### *Two-Pass Assembler and CPU Emulator*

<div align="center">

**Modern C++ • Compiler Design • Computer Architecture**

</div>

<div align="center">

📂 **Repository:** https://github.com/Rahul-1-eng/simplex-assembler-emulator

</div>

---

## 📖 Overview

Built a complete assembler and emulator for a custom **32-bit Instruction Set Architecture (ISA)** from scratch.

The project implements the complete flow from parsing assembly instructions and resolving symbols to generating machine code and executing programs inside a simulated processor.

---

## ✨ Features

* Two-pass assembler
* Lexer and parser
* Symbol table generation
* Label resolution
* Object code generation
* Memory simulation
* Register simulation
* Instruction execution
* Execution tracing
* Error diagnostics
* Listing file generation

---

## 🏗️ Implementation

| Component | Description                              |
| --------- | ---------------------------------------- |
| Lexer     | Token-based lexical analysis             |
| Parser    | Recursive-descent parser                 |
| Assembler | Two-pass assembler with label resolution |
| Emulator  | Fetch–Decode–Execute CPU simulation      |
| ISA       | Custom 32-bit instruction format         |
| Runtime   | Simulated registers and memory           |

---

## ⚡ Engineering Highlights

* Built entirely using **Modern C++**.
* Implemented a complete compiler-style pipeline from lexical analysis to execution.
* Simulated a custom CPU architecture with registers and memory.
* Added execution tracing and error diagnostics.
* Validated the implementation using sorting, searching, and factorial programs.
